The experimental RiftCLI patch lifecycle and the later native RiftCLI core have both been permanently retired. Older patch notes describe historical experiments only; they are not source-of-truth instructions for builds, shell commands, execution authority, or repository work.

Preserved engineering principles: inspect real source and dependency ownership before edits; use incremental verified patches; bind changes to source identity and checkpoints; validate code, docs, security, tests and real device behavior; keep execution authority outside model text; never claim promotion before proof.
