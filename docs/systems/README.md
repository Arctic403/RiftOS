# RiftOS Systems

Each directory under `docs/systems/` is an ownership boundary with its own README. The master navigation and maintenance contract is [`../README.md`](../README.md); the file-by-file ownership ledger is [`../SOURCE_OWNERSHIP.md`](../SOURCE_OWNERSHIP.md).

System READMEs document current source behavior, not roadmap intent. When code moves across boundaries, update both the old and new owning README plus the ownership ledger in the same patch.
