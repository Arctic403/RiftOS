# Runtime Capability Reporting

## Verification status

**VERIFIED AGAINST CURRENT SOURCE — 2026-09-17.**

## Purpose

The current APK does not expose `src/riftruntime.js` as a live global capability-report module because that file is not packaged by Gradle.

Runtime capability truth is therefore distributed across native owners and their explicit state/results.

## Source ownership

Retained reference source:
- `src/riftruntime.js` — historical web-runtime capability object; Node/reference only in the current APK architecture.

Live capability sources include:
- `BuildConfig` fields generated by Gradle — version/source/build provenance;
- `RiftNativeShell` native/info/system results;
- `RiftToolHost.manifest()` / `rift_info` — MCP capability catalog;
- `RiftBrowserEngine.state()` / browser state — renderer capabilities;
- `RiftBrowserAppHost` — installed-app capability allowlist and grants;
- `RiftMcpRuntime` — process-owned service availability.

## Critical invariants

- do not use `window.RiftRuntime` as proof of current APK capability;
- report only implemented native behavior;
- capability reporting does not grant authority;
- build/renderer/tool capabilities should be sourced from their owner rather than duplicated into a stale global table;
- secrets/device identifiers must not appear in capability reports.

## Failure signatures

- documentation cites a `RiftRuntime` flag for live native behavior → stale reference-source claim;
- capability UI disagrees with owner state → duplicated truth source;
- model client assumes a tool from documentation instead of MCP manifest → connector-state mismatch.

## Fix map

MCP capabilities → `RiftToolHost` / `RiftMcpServer`.

Shell/system capability info → `RiftNativeShell`.

Browser capabilities → `RiftBrowserEngine` implementation.

Installed-program grants → `RiftBrowserAppHost`.

Build provenance → Gradle `BuildConfig`.

## Validation

Compare live owner state to claimed capability documentation. Do not validate current APK features by evaluating `src/riftruntime.js`.
