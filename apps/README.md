# Repository Apps Directory

This source directory is currently reserved and contains no shipped app packages. Runtime-installed `.rift` applications live in RiftFS, not here.

The package/import/export/registry system is documented in [`../docs/systems/apps/README.md`](../docs/systems/apps/README.md). RiftRT execution is documented in [`../docs/systems/riftrt/README.md`](../docs/systems/riftrt/README.md).

If source-controlled first-party apps are added here later, give each app directory its own README and add its source files to `docs/SOURCE_OWNERSHIP.md`.
